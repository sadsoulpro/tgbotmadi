# «Точка опоры» — Telegram-бот диагностики

Готовый блок из семи аудио по ТЗ. После него бот показывает персональный результат, предлагает продолжить серию или перейти к записи и запрашивает телефон с возможностью отказа. Данные, медиа, тексты и настройки хранятся локально у владельца.

Для VPS с уже работающим сайтом см. [инструкцию развёртывания](deploy/README.md). Контейнер бота не занимает публичные порты 80/443.

## Запуск на Windows

1. Создайте Telegram-бота через BotFather и скопируйте токен.
2. Установите Python 3.12 или новее.
3. В PowerShell, находясь в этой папке:

   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   if (-not (Test-Path .env)) { Copy-Item .env.example .env }
   ```

4. При первой установке заполните `.env`: `BOT_TOKEN`, длинный случайный `ADMIN_PASSWORD`, при наличии — `BOOKING_URL` и `CONTACT_URL`. Ссылки должны начинаться с `https://`. В этой рабочей папке токен и пароль уже настроены. `.env` исключён из Git.
5. Запустите:

   ```powershell
   .\.venv\Scripts\python.exe -m app.main
   ```

   Для фонового запуска используйте `.\start.ps1`, для остановки — `.\stop.ps1`. Логи: `data/bot.stderr.log` и `data/bot.stdout.log`.

6. Откройте `http://127.0.0.1:8080/admin` на том же компьютере. Логин по умолчанию — `owner`, пароль — из `.env`.

Для непрерывной работы компьютер/сервер должен быть включён. Для удалённого доступа к админке используйте HTTPS через обратный прокси; стандартная конфигурация слушает только локальный адрес. Не запускайте второй экземпляр бота с тем же токеном одновременно.

Токен предоставлен владельцем и уже внесён в локальный `.env`. Для проверки связи без запуска бота выполните `.\.venv\Scripts\python.exe -m app.check_connection`. Пароль админки сгенерирован и находится в строке `ADMIN_PASSWORD` файла `.env`.

## Что настроить перед публикацией ссылки

- В админке откройте **Части** и проверьте семь аудио и две карточки. Начальные файлы уже привязаны к частям. У частей 2 и 4 в исходной папке лежат дубли; по умолчанию выбран файл, наиболее близкий к названию из ТЗ.
- В **Настройках** укажите `booking_url` и `contact_url`. Эти значения можно задать также в `.env`, но настройки из админки имеют приоритет. Если ссылка на запись не задана, кнопка личного разбора в результате скрыта.
- В **Текстах** отредактируйте формулировки. Приветствие из PDF внесено с уточнённой по MP3 длительностью. Сохраняйте переменные в фигурных скобках.
- В приветствии диапазон длительности уточнён по самим MP3: некоторые записи короче 4 минут, одна длится около 9 минут 28 секунд. Текущий текст сообщает «примерно от трёх до десяти минут».
- Ссылки для Instagram: `https://t.me/ИМЯ_БОТА?start=inerciya`, `...?start=nadryv` и другие метки латиницей, цифрами, `_` или `-` до 64 символов.

## Поведение

- Повторный `/start` оставляет прежний источник, шаг и оценки. `/continue` возвращает к текущему шагу. `/restart` начинает новое прохождение, сохраняя прежний результат.
- Оценки 0–10 ставятся кнопками после частей 4–7. В результате их можно изменить до выбора продолжения. Правило безопасности имеет приоритет над остальной классификацией и скрывает запись на разбор.
- Телефон запрашивается после результата. Отказ не мешает продолжать. При наличии следующих частей запрос повторится один раз ближе к концу серии.
- Напоминания отправляются через 24 часа и через 3 дня без действия пользователя. Всего не более двух напоминаний на пользователя; возвращение в бот не увеличивает этот лимит.
- В админке доступны воронка, источники, распределение оценок, список пользователей, CSV по таблицам и полная SQLite-копия. Факт прослушивания Telegram не раскрывает: событие «открыл часть» означает, что бот доставил аудио.
- Администратор может вручную отметить запись на разбор в списке пользователей. Для автоматической отметки сервис записи может отправить `POST /booking-webhook` с JSON `{"telegram_id": 123}` и заголовком `X-Booking-Secret`, если задан `BOOKING_WEBHOOK_SECRET`.

## Продолжение серии

После седьмого аудио контент следующих частей в переданных файлах отсутствует. Если частей больше нет, кнопка «Слушать дальше» показывает уведомление о будущем продолжении. Новые части добавляются в админке как аудио, картинка, оценка, текстовый ответ или кнопка. Они создаются выключенными; загрузите нужный файл и включите часть. Текстовые и числовые ответы сохраняются в таблице `answers` и доступны в CSV.

## Данные и бэкап

База по умолчанию — `data/bot.sqlite3`, загруженные медиа — `data/media`. Сохраните обе папки при переносе проекта. Исходные семь MP3 и две PNG лежат рядом с приложением и также должны оставаться на месте либо заменяться через админку. В админке доступна резервная копия базы. Список нажатий и время шагов находится в CSV `events.csv`.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты покрывают классификацию, сохранение прогресса, повторный проход, админку, медиа, напоминания и полный сценарий семи частей на имитированном Telegram API. Для реального запуска нужен токен BotFather и действующая ссылка на запись.
